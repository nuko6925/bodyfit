# Body Fit

非対応衣装をアバターの体型に合わせ、体への貫通を補正する VRChat アバター改変用ツールです。
[Modular Avatar](https://modular-avatar.nadena.dev/ja/) の Merge Armature で着せた衣装に、コンポーネントを 1 つ付けるだけで動きます。

- ビルド時 (NDMF) に処理するので、元の衣装・プレハブ・メッシュは一切変更しません
- 補正は衣装メッシュに追加される BlendShape `BodyFit` なので、0 にすれば補正前に戻せます
- 変換プロファイルや、変換元アバターの素体は不要です

ボーンのスケールと MA Scale Adjuster をプリセットで一括適用する **Body Scale** も同梱しています。

## 動作環境

- Unity 2022.3
- VRChat SDK Avatars 3.5.0 以降
- Modular Avatar 1.9.0 以降 / NDMF 1.4.0 以降

## インストール

### VCC / ALCOM

1. VCC (または ALCOM) の Settings > Packages > Add Repository に次の URL を追加します
   `https://nuko6925.github.io/bodyfit/index.json`
2. プロジェクトの Manage Project で **Body Fit** を追加します

### 手動

[Releases](https://github.com/nuko6925/bodyfit/releases) の zip を展開し、プロジェクトの `Packages/tech.chiffon.bodyfit` に置きます。

## 使い方 (Body Fit)

1. いつも通り衣装をアバターの中に置き、MA の Setup Outfit (Merge Armature) を設定します
2. 衣装のルートに **Add Component > Body Fit > Body Fitter** を追加します
3. **Bodies** に体のメッシュを指定します
   - 空なら、胴・腕・脚にウェイトが乗っているメッシュを体として自動で選びます。VRChat 向けアバターに多い「`Body` が頭部」の場合も、胴体のメッシュ (`Body_base` など) が選ばれます
   - 選ばれたメッシュは Inspector に表示されます。違っていれば手動で指定してください
4. スカートの裾や袖口など、体から離れて揺れる部分のボーンを **Exclude Bones** に入れます (任意)
5. **プレビュー** を押すと、ビルド後の見た目をシーン上で確認できます

あとはアップロードするだけです。

### 処理の流れ

| 段階 | 内容 |
|---|---|
| 関節合わせ | 衣装のボーンの位置・スケール・Scale Adjuster を、アバターの対応するボーンに揃えます (Merge Armature の前)。衣装のルートを動かして置いた場合は、そのずれ (例: Y +0.01) を保ったまま揃えます。指のように名前の付け方が違うボーンは向きで対応付け、MA が統合できるよう名前をアバターに合わせます |
| 太さ合わせ | ボーンごとに体と衣装の断面を比べ、衣装の太さを体に合わせます |
| 靴の中の足 | 靴が足を囲んでいれば、靴の中の足を BlendShape `BodyFit_HideFeet` で隠します |
| 貫通補正 | 衣装を布として扱い、体にめり込んだ部分を押し出します。重なった服の前後関係や、ボタンなどの小パーツは崩さないようにしています |

### 設定

普段は「基本」の項目だけで十分です。

#### 基本

| 項目 | 説明 |
|---|---|
| Bodies | 貫通判定に使う体のメッシュ |
| Exclude Bones | 補正しないボーン (子孫も含む) |
| Per Mesh | メッシュごとの個別設定。「検出された衣装メッシュを個別設定に追加」で一括作成できます |

Per Mesh では次の設定ができます。

- **tight**: 体に密着させます。ニーハイ・タイツ・手袋など、ぴったりした服に使います。体から浮いている部分も、体の表面 + margin まで引き寄せます。生地に厚みがある場合や上にベルトが重なっている場合は、一番内側の面だけを引き寄せ、残りはそれに付いてきます。引き寄せ先は同じ部位 (胴・左右の腕・左右の脚) の体の面に限ります。垂れ下がるストラップなど、体から離れているべき部分を含むメッシュに使う場合は、その部分のボーンを Exclude Bones に入れてください
- **skip**: そのメッシュを補正しません。補正しない場合も、他の衣装を覆う面としては判定に使われます
- **layer**: 重ね順です。大きいほど外側になります。シャツとジャケットの前後が入れ替わるときに使います
- **drape**: パーカーなどゆったりした服用です。体のくぼみ (胸の上下・谷間など) をこの範囲で埋めた形に対して判定し、出っ張った所から出っ張った所へ布が張った形にします。胸の上が段になって飛び出す場合に 40〜80 mm を目安に設定してください
- **margin / maxDistance / reverseDepth / falloff**: 下の「貫通補正」の同名の項目を、そのメッシュだけ変えます。falloff は 0 なら全体の設定を使います。パーカーなどゆったりした服で、胸などに生地が貼り付いたようになる場合は 60〜100 mm にすると、押し出しが広く分散して自然に垂れます

#### 詳細設定 > 体型合わせ

| 項目 | 既定値 | 説明 |
|---|---|---|
| Align Joints | オン | 衣装の関節をアバターに揃えます |
| Copy Body Shape | オフ | アバター側の体型改変 (ボーンのスケールと MA Scale Adjuster) を衣装にも写します。衣装がもともとその素体に合っている (対応衣装) 場合に使います。非対応衣装では長さは関節の位置合わせ、太さは体型合わせで合わせるので、オンにすると二重に掛かります |
| Auto Proportion | オン | 衣装の太さを自動で合わせます |
| Proportion Strength | 1 | 推定した倍率をどれだけ使うか |
| Proportion Range | 0.85 – 1.2 | 太さの倍率の下限・上限 |
| Loose Ratio | 1.35 | 衣装の内径が体のこの倍以上なら、元からゆったりしたデザインとみなして縮めません |
| Hide Feet In Shoes | オン | 靴の中の足を隠し、靴は拡縮しません |
| Fit Bust | オン | 衣装の胸が体の胸より大きくて浮いている場合に、その衣装のゆとり (胸の高さの脇・背中での隙間) まで引き寄せます。アバターに胸のボーン (Breast 等) が必要です |

#### 詳細設定 > 貫通補正

| 項目 | 既定値 | 説明 |
|---|---|---|
| Margin | 1.5 mm | 体の表面から最低限離す距離 |
| Max Distance | 50 mm | この距離以内の頂点を判定します。深く埋まっている場合は大きくします |
| Reverse Depth | 20 mm | 粗いポリゴンの面の中央から体が突き抜ける箇所を、この深さまで検出します |
| Body Smoothing | 0 (オフ) | 体の細かい凹凸 (胸の先など) を、布が張ったようにならしてから判定します。服に体の細部の形が浮き出るときに 10〜15 mm 程度にしてください。重ね着の多い衣装では袖口などが崩れることがあります |
| Keep Hidden Layers | オン | 表地が体の外にあれば、その内側の層 (裏地・襟やフードの内側など) が体にめり込んでいても押し出しません。見えない層を押し出して表地まで膨らむのを防ぎます |
| Falloff | 30 mm | 押し出した部分の周囲がなじむ範囲 |
| Solver Iterations | 60 | ソルバーの反復回数 |
| Layer Follow Distance | 10 mm | この距離以内で重なった別の層の前後関係を保ちます |
| Island Max Size | 50 mm | これ以下の独立したパーツ (ボタン等) は変形させず平行移動します |

#### 詳細設定 > その他

| 項目 | 説明 |
|---|---|
| Targets | 補正する衣装メッシュ。空ならこのオブジェクト以下のすべて |
| Ignore Body Bones | 体のうち判定に使わない部位 |
| Exclude Descendants / Exclude Weight Threshold | Exclude Bones の子孫も含めるか / どれだけウェイトが乗った頂点を除外するか |
| Blend Shape Name / Weight | 追加する BlendShape の名前と初期値 |
| Order | 複数の Body Fitter がある場合の処理順 |
| Verbose Log | ボーンごとの倍率などの詳しいログを Console に出します |

### デバッグ表示

プレビュー中は、補正した頂点がシーンビューに線で表示されます (補正前 → 補正後)。

- 赤: 体の内側にあったので押し出した頂点
- 橙: 体が衣装の面を突き抜けていたので押し出した頂点
- 緑: 密着 (tight) で体へ引き寄せた頂点
- 水色: 周囲に合わせて動いただけの頂点

## 使い方 (Body Scale)

アバターのボーンに、決まったスケールと MA Scale Adjuster をまとめて設定します。体型改変の値を何体ものアバターで使い回すためのツールです。

1. Project ウィンドウで **右クリック > Create > Body Fit > Body Scale Preset** を選び、プリセットを作ります
2. プリセットに、ボーンごとの値を登録します
   - **path**: Armature からの相対パス (例: `Hips/Upper_leg_{S}`)。`{S}` は `L` と `R` に展開されます。大文字小文字と区切り文字 (`_` `.` `-` 空白) は無視されます
   - **setScale / scale**: ボーン自体のスケール (長さも太さも変わります)
   - **setAdjuster / adjuster**: MA Scale Adjuster (このボーンに直接付いたメッシュの太さだけ変わります)
3. **Tools > Body Fit > Body Scale** を開き、プリセットを指定し、Hierarchy でアバターを選んで **適用** を押します

衣装には適用しなくて構いません。Body Fitter の関節合わせが、ビルド時にアバター側の値を衣装へ写します。

## 制限事項

- 自動化はしていますが完璧ではありません。デザインによっては貫通が残ったり、不自然な変形が出たりします。BlendShape `BodyFit` のウェイトや Per Mesh の設定で調整してください
- 体型合わせと靴の判定には、Humanoid として設定されたアバターが必要です
- 揺れものなど PhysBone で動く部分は、補正前の位置で計算されます。必要に応じて Exclude Bones に入れてください
